# AccountPilot AI — Design System

## Product Personality

AccountPilot should feel calm, precise, executive, and information-rich. It is an enterprise decision workspace, not a consumer chatbot or a student dashboard.

## Reference Direction

The supplied Lovable preview is access-restricted, but its visible design language informs the direction: a warm off-white canvas, compact clean type, soft neutral borders, restrained elevation, and a vivid pink-to-blue gradient accent. AccountPilot applies this direction while retaining an enterprise data density.

## Typography

- Interface and body: DM Sans, 15px base size.
- Headings: Plus Jakarta Sans, 700–800 weight, tight negative tracking.
- Page title: 29–32px.
- Section title: 15–18px.
- Labels and metadata: 10–12px, medium to bold.

## Layout and Components

- Use a persistent 258px desktop sidebar and 74px collapsed tablet sidebar.
- Use an off-white content canvas with white cards, 13–16px radii, and one-pixel warm borders.
- Use 8px spacing increments; 14–20px gaps between cards.
- Keep primary actions dark by default; use blue/pink gradient accents for AI-specific moments and the floating assistant.
- Preserve clear contrast, keyboard focus visibility, and semantic labels.

## Motion

- Keep interaction transitions under 250ms.
- Use subtle card lift, color shift, and loading shimmer only where it reinforces feedback.
- Avoid distracting motion in high-density tables and analytics.
